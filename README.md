# 🎈 Alfabetowa Zabawa

Prosta apka do nauki polskiego alfabetu dla dzieci. Dwie gry:

1. **Znajdź przedmiot** – przechodzisz przez alfabet po kolei i wybierasz obrazek zaczynający się na wskazaną literę.
2. **Ułóż litery** – rozsypane litery trzeba poukładać alfabetycznie.

Trzy poziomy trudności (🐣 Łatwy / 🐰 Średni / 🦉 Trudny), dźwięki, gwiazdki i konfetti.

## Uruchomienie lokalne
Wystarczy otworzyć plik `index.html` w przeglądarce (podwójne kliknięcie). Nie wymaga instalacji.

## Wdrożenie
Statyczna strona – Vercel serwuje `index.html` bez konfiguracji.
